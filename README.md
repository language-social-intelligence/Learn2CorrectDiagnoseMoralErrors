# Learn2CorrectDiagnoseMoralErrors

The Human-scale AI chatbot demonstrates diagnosis-guided correction. Llama 3.2 3B Instruct drafts a reply. A trained Llama 3.2 1B reviewer diagnoses it, then the 3B model uses that diagnosis to revise the answer. The chat opens in **Light** mode. Visitors can also select **Fusion**.

- [Run the chatbot locally or deploy it with a public tunnel](second-look-web/README.md)
